# Egbert's Job Match Desk — hourly-refreshed board

A live dashboard of remote Recruiter / Talent Acquisition / IT Recruiter /
Sourcing Specialist / Recruitment Consultant roles, matched against Egbert's
resume, refreshed **every hour automatically** — even when nobody is
chatting with Claude.

## What you need

- A **GitHub account** (free) — https://github.com/join
- 10 minutes for one-time setup
- Nothing else. No API keys, no paid services. It runs entirely on GitHub's
  free tier (Actions + Pages), and pulls from free public job APIs
  (Remotive, RemoteOK, WeWorkRemotely).

## Setup (one time)

1. **Create a new repository** on GitHub (public or private both work),
   e.g. `job-tracker`.
2. **Upload these files** into it, keeping the folder structure:
   ```
   job-tracker/
     .github/workflows/hourly-refresh.yml
     docs/index.html
     docs/jobs.json
     fetch-jobs.mjs
     package.json
     README.md
   ```
   Easiest way: on the repo page, click "Add file → Upload files" and drag
   the whole folder in, or use `git push` if you're comfortable with git.
3. **Enable GitHub Pages**: Repo → Settings → Pages → under "Build and
   deployment", set Source = "Deploy from a branch", Branch = `main`,
   folder = `/docs`. Save. GitHub will give you a URL like
   `https://yourusername.github.io/job-tracker/` — that's your live board.
4. **Enable Actions**: Repo → Actions tab → if prompted, click "I understand
   my workflows, enable them."
5. **Run it once manually** to populate real data immediately: Actions tab →
   "Hourly job refresh" workflow → "Run workflow" button. After ~30 seconds,
   `docs/jobs.json` will be updated with real postings and your Pages site
   will reflect them (may take a minute to redeploy).

From here it runs **every hour on its own** — no further action needed.

## What it does each hour

- Pulls current listings from Remotive, RemoteOK, and WeWorkRemotely's HR/
  Recruiter category
- Filters titles for: Recruiter, Recruitment Consultant, IT Recruiter,
  Talent Acquisition (Specialist), Sourcing Specialist
- Drops listings whose location text explicitly excludes India (e.g.
  "US Only," "UK Only")
- Keeps postings from roughly the last 7 days when a date is available
- Commits the result to `docs/jobs.json`, which the dashboard reads live

## What the dashboard shows per job

- Match score (based on resume keyword overlap)
- What matches / what doesn't (positives & gaps)
- A generated cover letter (3 variants, regenerate button, copy button)
- ATS tailoring tips for that specific listing
- A LinkedIn search link to find real recruiters at that company (no
  fabricated names or emails — ever)
- A status tracker (New / Saved / Applied / Interviewing / Rejected) and a
  notes field, saved in your browser so it persists across visits

## Known limitations, honestly

- **Not every job board is covered.** LinkedIn, Naukri, and Indeed don't
  offer free public APIs, so this pulls from boards that do (Remotive,
  RemoteOK, WeWorkRemotely). You'll still want to check LinkedIn/Naukri
  yourself periodically — I can also do a manual deep search there anytime
  you ask me in chat.
- **"Posted date" isn't always available** from these APIs; where missing,
  the card says "date unknown — verify on source" rather than guessing.
- **Match scores and cover letters are a starting draft**, generated by
  simple keyword matching in the browser — proofread before sending.
- **The tracker is stored per-browser** (localStorage), not in the cloud —
  it won't sync between your phone and laptop. If you want that, the next
  step is swapping `docs/jobs.json` storage for a small database (e.g.
  Supabase's free tier), which I can help you set up if you want to go
  further.
